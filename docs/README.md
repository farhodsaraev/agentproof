# Agentproof documentation

This folder holds all documents of the Agentproof project. The [README](../README.md) in the project root stays there, because GitHub shows it on the project page. The README tells you how to install Agentproof, change its settings and build it.

## Start here

| Document | What it gives you | Status |
| --- | --- | --- |
| [about.md](about.md) | What Agentproof is, how it works, what it checks and its known limits today | Current |
| [roadmap.md](roadmap.md) | The plan: what is done, what comes next and in which order. Each item has an ID and a status | Current. The work continues from this file |

## Rules for these documents

- Write all text in ASD-STE100 Simplified Technical English. Use short sentences, the active voice and one meaning for each word.
- An instruction has a maximum of 20 words. A description has a maximum of 25 words.
- Use the terms from the glossary in [about.md](about.md).
- Update [roadmap.md](roadmap.md) when an item starts or ends. The last sections of the roadmap tell you how.
- Put each new document in this folder. Add a line for it to this file.
- Use file names in lowercase letters with hyphens, for example `release-process.md`.
